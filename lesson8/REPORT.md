# Урок 8 — отчёт (Deal Radar v1.0)

Данные демонстрационные, цены вымышленные.

## 1. База и связи
Три таблицы: `stores` (магазины) ← `products` (`store_id` — внешний ключ на `stores.id`) ← `price_history` (`product_id` — внешний ключ на `products.id`). Внешний ключ гарантирует, что у товара есть существующий магазин, а у замера цены — существующий товар. `--demo` создаёт 8 товаров и 16 замеров.

## 2. SQL-аналитика (`sql/analytics.sql`)
- COUNT/AVG/MIN/MAX: 8 товаров, средняя цена 68893.75 ₸, минимум 8500 ₸, максимум 299000 ₸ (после импорта CSV).
- GROUP BY + JOIN: AudioMall — 25875 ₸, GadgetCity — 50666.67 ₸, TechShop — 115800 ₸.
- Падения цены: оконная функция `ROW_NUMBER()` берёт два последних замера каждого товара.

## 3. Класс Database
- `add_product()` — добавляет товар или обновляет его по URL (`ON CONFLICT`) и каждый раз пишет новый замер в `price_history`.
- `find_cheaper(limit, keyword)` — товары дешевле `limit`; слово ищется через `casefold()`, чтобы работала кириллица.
- `price_history(id)` — все замеры товара по порядку дат.

## 4. История и график
Импорт: `python main.py --import-csv data/new_prices_example.csv` (один раз!). График: `python main.py --chart 2` → `reports/price_chart.png` (Мышь Aero: 12000 → 9000 → 8500).
Формула падения: **(старая − новая) / старая × 100%**. Для мыши: (9000 − 8500) / 9000 × 100 ≈ 5,56%.

## 5. Отчёт и ИИ
`reports/report.txt` содержит статистику и топ падений: Наушники SoundX −25%, Веб-камера Clear −25%, Мышь Aero −5,56%, Монитор −5,22%, Ноутбук −5,08%. Числа сверены с базой. ИИ-комментарий нужно получать только по этим данным; снижение цены не гарантирует выгоду.

## 6. Запуск и тесты
`pip install -r requirements.txt`, `python main.py --demo`, `python main.py`; тесты: `python -m unittest discover -s tests` — 2 теста проходят.
