# Урок 7 — отчёт

## 1. База и ключи
Таблица `products`: `id` — первичный ключ (уникальный номер, автоувеличение); `name` — название; `price` — цена (не меньше 0); `rating` — рейтинг от 0 до 5; `url` — ссылка, **UNIQUE**: два товара с одинаковым URL в таблице быть не могут.

## 2. Импорт
`python main.py import` → «Прочитано строк CSV: 10. Добавлено новых товаров: 9».
Строка «Мышь Logitech M185» встречается в CSV дважды с одним URL. Из-за `UNIQUE` и `INSERT OR IGNORE` второй раз она пропускается, поэтому 10 строк → 9 записей. Десятый товар в базе («USB кабель») добавлен вручную командой `add` (бонус).

## 3. Квест из пяти запросов (`sql/quest.sql`)
| № | Запрос | Результат |
|---|---|---|
| 1 | самый дешёвый: `ORDER BY price ASC LIMIT 1` | USB кабель — 1490 |
| 2 | топ-5 по рейтингу: `ORDER BY rating DESC LIMIT 5` | SSD Kingston 4.9, Мышь Logitech 4.8, Ноутбук Lenovo 4.7, JBL Tune 4.6, USB кабель 4.5 |
| 3 | поиск по слову: `LIKE '%Мышь%' OR LIKE '%мыш%'` | Коврик для мыши, Мышь Logitech M185 |
| 4 | дешевле 20000: `WHERE price < 20000` | 6 товаров, от USB кабеля (1490) до веб-камеры (19990) |
| 5 | дубликаты: `GROUP BY url HAVING COUNT(*) > 1` | пусто — `UNIQUE` не пускает повторы |

Примечание: `LIKE` в SQLite не различает регистр только у латиницы, поэтому `'%мышь%'` не находит «Мышь» с большой буквы, а `'%мыш%'` не находит «Мышь Logitech» — пришлось использовать два шаблона.

## 4. Python и безопасность
- `sqlite3.connect(путь)` — открывает (или создаёт) файл базы.
- `cursor` — объект, через который выполняются запросы и читаются результаты.
- `execute(sql, параметры)` — выполняет один запрос; `executemany` — много раз с разными данными.
- `commit` — подтверждает изменения; в `with connection:` это происходит автоматически.

Безопасно: `cursor.execute('SELECT * FROM products WHERE name = ?', (user_input,))` — данные передаются отдельно от SQL. Небезопасно: `f"... '{user_input}'"` — ввод становится частью кода (SQL-инъекция).

## 5. Бонус
Через `main.py add` добавлен товар «USB кабель» (1490, рейтинг 4.5); цену можно менять командой `update-price`.
